# Changelog

## 1.0.1

- Fixed `RegisterCallback` compatibility with multicharacter resources.
- Added support for standard, table-based and wrapper callback registration.
- Added callback existence/removal helpers and clearer missing-callback logging.

## 1.0.0

Initial public release.

- Unified framework bridge for vRP, ESX, QBCore and QBox
- Inventory, target and dispatch bridges
- NPC, vehicle, object, zone, blip and animation helpers
- Callback, permission, logging and database helpers
- Garage, billing, society, fuel and vehicle-key integrations
- Framework-independent character API
- Optional legacy/Flax vRP multicharacter compatibility patch
- GitHub auto updater with protected local configuration
